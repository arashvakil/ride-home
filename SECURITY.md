# Security

Ride Home is an early project; it does not offer a security support SLA. Use the latest
reviewed source and inspect accessibility access before enabling it on your device.

For a sensitive vulnerability, use GitHub's **Report a vulnerability** option when
available. If it is unavailable, open an issue asking for a private reporting channel
without including exploit details, private data, credentials or signing material.

If the Home tab behaves unexpectedly, disable Ride Home navigation in Android
Accessibility settings and select a known working launcher. Keep that alternative
installed while testing Ride Home. A report should include the Android version and
redacted reproduction steps; never post an ADB serial or account/ride history.
